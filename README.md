# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple project that calculates the interest earned or paid on a principal amount over a specified period at a fixed rate of interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Input Fields

- **Principal:** The initial amount of money.
- **Rate of Interest:** The annual interest rate in percentage.
- **Time:** The duration in years.

## Example

If the principal is 1000, the annual interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = 1000 + 100 = 1100

## Technology Used

- Bash scripting (Simple Interest Calculator)
- Git and GitHub

## How to Use

1. Enter the principal amount.
2. Enter the annual rate of interest.
3. Enter the time period in years.
4. Calculate the simple interest using the formula above.
